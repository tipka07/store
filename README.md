# Магазин с товарами

Учебный мини-проект на JavaScript, представляющий собой интерфейс небольшого магазина с товарами и корзиной.

В проекте реализована работа с товарами, их добавление и удаление, поиск, добавление товаров в корзину, применение скидок и автоматический расчёт итоговой стоимости.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- SweetAlert2
- List.js
- LocalStorage API
